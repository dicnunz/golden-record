# Sagan

Decode a real digitization of the Golden Record picture signal using the engraved cover as the reconstruction specification. Infer synchronization from signal, retain derivations, render recovered pictures in a reveal video.

## Deliverables

Reproducible fetch, process, verify, and video commands; original inputs identified by URL and SHA-256; outputs generated by the pipeline; concise README with commands, measured results and limitations; source and dependency licensing. Demo target: 1920×1080 H.264, intentional typography, measured pacing, actual result imagery.

## Acceptance

Run against downloaded source data, inspect outputs visually, test domain invariants, inspect the encoded video, and verify uploaded repository contents. Failed stages must remain explicitly incomplete.
